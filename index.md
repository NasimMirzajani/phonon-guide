A growing field guide to **phonons, phonon polaritons, twist, and multilayer van der Waals heterostructures**, written for a senior scientist who wants physical intuition and literature context without textbook-length derivations.

**Start here:** [Briefing 01 — Reciprocal space]({{ '/lessons/01-reciprocal-space/' | relative_url }}) → [Briefing 02 — Normal modes]({{ '/lessons/02-normal-modes/' | relative_url }}) → [Briefing 03 — Acoustic and optical phonons]({{ '/lessons/03-acoustic-optical/' | relative_url }}).

## How the library works

Each new lesson is a small **Markdown (`.md`) file**. Upload it to `lessons/` in your GitHub repository. GitHub Pages automatically renders it in the same style and includes it in the sidebar. Equations use LaTeX notation, displayed via MathJax. No HTML editing or navigation editing required.

## The 20-briefing roadmap {#curriculum}

| Week | Sequence | Themes |
|---|---|---|
| **1 — Foundations** | 01–05 | Reciprocal space; normal modes; acoustic/optical phonons; symmetry; dielectric response |
| **2 — Twist and interlayers** | 06–10 | Shear/breathing; stacking registries; moiré reciprocal space; zone folding; mode hybridization |
| **3 — Polaritons** | 11–15 | LO/TO and Reststrahlen; dielectric tensors; polariton dispersion; hyperbolicity; twist-tunable modes |
| **4 — Experiments & frontier** | 16–20 | Raman; IR/nano-IR; s-SNOM/EELS; moiré phonons; evaluating new twisted-polariton research |

> **Publication model:** ChatGPT generates the teaching content. You upload the lesson file. GitHub Pages handles rendering, search/navigation and publication. No second AI subscription or API call.
